Pengenalan Lingkungan Praktikum dan Kakas Pemodelan UML
A. Tujuan Praktikum
1. Mengenal lingkungan praktikum dan perangkat lunak yang digunakan untuk pemodelan UML.
2. Mampu membuat workspace dan menyusun struktur folder proyek dengan rapi.
3. Memahami penggunaan fitur dasar pada aplikasi pemodelan UML.
4. Mampu membuat, menyimpan, dan membuka kembali file diagram untuk memastikan file dapat diedit.
B. Dasar Teori
UML (Unified Modeling Language) merupakan bahasa pemodelan yang digunakan untuk menggambarkan, merancang, dan mendokumentasikan suatu sistem. UML membantu pengembang memahami struktur serta proses kerja sistem melalui diagram.

Kakas pemodelan UML merupakan perangkat lunak yang digunakan untuk membuat diagram, seperti draw.io (diagrams.net), Visual Paradigm, dan StarUML. Dalam praktikum ini, aplikasi digunakan untuk mengenal fitur dasar pembuatan diagram, mengatur elemen, serta menyimpan hasil pekerjaan.

Workspace merupakan ruang kerja yang digunakan untuk menyimpan dan mengelola seluruh file proyek agar tersusun secara sistematis dan mudah ditemukan kembali.
C. Hasil Praktikum
Pada praktikum pertemuan pertama, dilakukan persiapan lingkungan kerja dengan membuat workspace dan struktur folder untuk menyimpan file praktikum. Selanjutnya, dilakukan pengenalan aplikasi pemodelan UML, mulai dari membuat kanvas baru, menambahkan elemen diagram, menghubungkan elemen, hingga menyimpan hasil pekerjaan.

File diagram kemudian dibuka kembali untuk memastikan bahwa hasil pekerjaan tersimpan dengan baik dan masih dapat diedit. Selain itu, dilakukan pencatatan kegiatan praktikum melalui logbook.
D. Analisis
Praktikum ini memberikan pemahaman awal mengenai penggunaan aplikasi pemodelan UML dan pengelolaan file proyek. Penyusunan workspace yang terstruktur sangat penting agar file praktikum tidak tercampur dan mudah dikelola. Pengujian dengan membuka kembali file juga diperlukan untuk memastikan bahwa file yang disimpan bukan hanya berupa gambar, tetapi masih memiliki struktur yang dapat diedit.
E. Kesimpulan
Berdasarkan praktikum yang telah dilakukan, dapat disimpulkan bahwa pengenalan lingkungan praktikum merupakan tahap awal yang penting sebelum melakukan pemodelan sistem. Mahasiswa dapat memahami cara menyiapkan workspace, menggunakan fitur dasar aplikasi UML, serta menyimpan dan mengelola file proyek dengan baik.
